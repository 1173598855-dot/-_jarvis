# Project Scanner — 项目深度扫描技能

## 触发条件

"扫描项目"、"分析代码库"、"生成 PROJECT_ANALYSIS"、"技术债扫描"。
也可通过 `/scan` 手动激活。

---

## 执行协议

### 第一步：全面文件发现

调用 `Glob("**/*")` 获取项目所有文件列表。
调用 `Glob("**/*.json")` + `Glob("**/*.yaml")` + `Glob("**/*.toml")` 获取配置文件。
调用 `Glob("**/*.ts")` + `Glob("**/*.tsx")` + `Glob("**/*.py")` + `Glob("**/*.js")` 获取代码文件。

### 第二步：关键文件深度读取

根据文件类型，使用 `Read` 工具读取核心文件：
- `package.json` — 依赖分析
- `tsconfig.json` / `pyproject.toml` — 编译配置
- 入口文件（`index.ts`、`main.py` 等）— 架构入口点
- `CLAUDE.md` — 项目上下文

### 第三步：依赖关系分析

使用 `Grep` 搜索关键模式：
- `import` / `require` / `from xxx import` — 模块依赖
- `interface` / `class` / `type` — 类型定义
- `@/` / `../` — 路径引用

### 第四步：使用 Explore Agent 深度分析

调用 `Agent`（subagent_type: "Explore"）进行多维度分析：
- "分析项目架构，识别模块依赖关系和数据流向"
- "找出重复代码、死代码、低性能模式"
- "评估 TypeScript/Python 代码质量：类型安全、错误处理、测试覆盖"

### 第五步：生成 docs/reports/PROJECT_ANALYSIS.md

使用 `Write` 工具创建报告，必须包含：

```markdown

## 项目信息
- 项目名称：[名称]
- 主要语言：[TypeScript/Python/混合]
- 扫描时间：[ISO 时间戳]
```

---

## 输出物

- `docs/reports/PROJECT_ANALYSIS.md`（使用 `Write` 创建在报告目录）
- 返回扫描摘要给主代理

---

## 安全约束

- 仅读取，不修改任何文件
- 不执行任何有副作用的命令
- 所有分析基于静态代码审查
